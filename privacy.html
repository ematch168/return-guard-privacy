Return Guard 隱私權政策

最後更新日期：2026 年 10 月 9 日
Return Guard 是協助賣家管理 Shopee 賣家中心退貨／退款案件的 Chrome 擴充功能。Return Guard 並非 Shopee 或 Sea Limited 官方產品，也未獲其背書。

1. 擴充功能存取的資料

為提供退貨／退款案件檢查與處理功能，Return Guard 可能在使用者已登入的 Shopee 賣家中心工作階段中存取案件與訂單資訊、必要的買家識別資訊、是否存在聊天紀錄的中繼資料，以及完成使用者要求之操作所需的暫時性驗證／工作階段資訊。

2. 資料用途

上述資料只用於 Return Guard 的單一用途：檢查退貨／退款案件、辨識是否存在既有聊天、維護案件處理狀態，以及在使用者啟用或要求時執行封鎖等相關操作。

3. 本機與暫時性儲存

設定、自動排程及最小化處理結果會保存在 Chrome 本機儲存空間。訂單快取索引以 SHA-256 衍生值保存。Return Guard 不會刻意將買家姓名、買家 ID、聊天內容、Conversation ID、Cookie、Authorization、CSRF Token 或完整請求網址寫入長期處理紀錄。

目前瀏覽器工作階段所需的 Shopee request context 可能暫存在 chrome.storage.session，但不會寫入長期備份，並會隨瀏覽器工作階段結束而失效。

4. 自動排程

只有使用者主動開啟自動排程後，Return Guard 才會依設定的每幾小時或每幾天檢查案件。Chrome 關閉期間不會執行；重新開啟 Chrome 後可恢復原排程，必要時補跑一次錯過的排程。

5. 處理紀錄備份

使用者可手動匯出與匯入處理紀錄供換機使用。備份不包含 Shopee Cookie、Authorization、CSRF Token、聊天 Session、帳號密碼或其他登入憑證。

6. 匿名問題回報

匿名問題回報預設關閉。只有使用者自行開啟「匿名問題回報」後，Return Guard 才會將最小化的技術錯誤統計傳送到 Return Guard 問題回報服務，以協助發現相容性及可靠性問題。

可能傳送的欄位僅限於：Return Guard 版本、Chrome 主要版本、技術事件類型、正規化錯誤碼、處理階段、HTTP 狀態碼、執行來源／傳輸方式、操作模式、auto-block/dry-run 布林設定，以及已處理／失敗／封鎖／待人工等彙總數量。

匿名問題回報不包含：

  • 訂單編號或訂單 ID
  • 買家 ID 或買家姓名
  • 商店 ID
  • Conversation ID
  • 聊天或訊息內容
  • 頁面或 request URL
  • Cookie
  • Authorization
  • CSRF Token
  • Shopee Session 值
  • 帳號密碼
  • 穩定的 Return Guard 安裝識別碼

如果問題回報服務暫時無法連線，符合上述限制的匿名技術資料可能暫存在本機佇列，稍後自動重試。關閉匿名問題回報時，待傳佇列會從 Return Guard 本機儲存中移除。

7. 問題回報資料如何保存

Return Guard 的問題回報後端會將收到的匿名技術事件直接彙整成「每小時統計」，設計上不保存逐一使用者事件歷史，也不將 IP 位址、商店識別、訂單識別、買家識別或穩定安裝識別碼寫入問題回報資料庫。

8. 資料分享與販售

Return Guard 不販售使用者資料，也不將 Shopee 帳號內容、訂單內容、買家資料、聊天內容或登入憑證提供給廣告商、資料仲介商或其他與功能無關的第三方。

若使用者開啟匿名問題回報，僅會將第 6 節列出的最小化技術統計傳送至 Return Guard 問題回報服務，用於維護與改善 Return Guard。

9. 廣告、信用與其他用途

Return Guard 不會將使用者資料用於廣告、信用評等、貸款、與擴充功能單一用途無關的個人輪廓，或轉售用途。

10. 使用者控制

  • 匿名問題回報可保持關閉，或隨時關閉
  • 可關閉自動排程
  • 可清除本機處理紀錄
  • 可匯出／匯入處理紀錄
  • 可解除安裝 Return Guard 以移除擴充功能本機資料

11. Chrome Web Store Limited Use

Return Guard 對使用者資料的使用遵循 Chrome Web Store Developer Program Policies 與 Limited Use 要求，並限制在提供或改善已揭露的單一用途。

12. 聯絡方式

若對 Return Guard 的隱私權或資料處理方式有疑問，請透過 Return Guard 的 Chrome Web Store 項目頁面聯絡發布者。
