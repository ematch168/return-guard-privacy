Return Guard 隱私權政策

最後更新日期：2026 年 9 月 19 日
Return Guard 是一款協助賣家管理退貨／退款案件的 Chrome 擴充功能。 本擴充功能的目的，是在使用者已登入的賣家中心工作階段中， 協助檢查案件、辨識聊天狀態、顯示處理結果， 並依使用者設定進行自動或手動處理。

1. 我們處理哪些資料

Return Guard 為了提供功能，可能會在使用者裝置上暫時處理下列資料：

  • 退貨／退款案件資訊
  • 訂單識別資訊
  • 買家識別資訊
  • 案件處理狀態
  • 是否存在聊天紀錄的狀態資訊
  • 目前已登入賣家中心工作階段所需的驗證資訊

Return Guard 不以提供本擴充功能以外的目的使用上述資料。

2. 登入與驗證資訊

Return Guard 可能在目前已登入的賣家中心工作階段中， 暫時使用網站本身產生的驗證資訊，例如：

  • Authorization 資訊
  • CSRF Token
  • 工作階段識別資訊
  • 與賣家中心 API 連線必要的暫時性參數

這些資訊僅用於完成使用者要求的賣家中心操作， 不會寫入 Return Guard 的長期處理紀錄備份， 也不會被用於登入其他服務。

3. 聊天資料

Return Guard 的用途是判斷買家是否存在聊天紀錄， 以決定案件是否需要人工確認。

擴充功能不以建立聊天資料庫為目的， 也不會將聊天內容上傳到 Return Guard 自有伺服器。

4. 本機儲存

Return Guard 會使用 Chrome 的本機儲存功能保存部分資料，例如：

  • 操作模式設定
  • 自動排程設定
  • 案件處理結果
  • 匿名化或雜湊後的案件識別索引
  • 處理紀錄備份所需資料

這些資料主要保存在使用者自己的瀏覽器環境中。

5. 備份與匯入

Return Guard 支援使用者手動匯出與匯入處理紀錄， 讓使用者在更換電腦後能延續同一商店的案件處理狀態。

匯出的處理紀錄不包含：

  • Shopee Cookie
  • Authorization 憑證
  • CSRF Token
  • 聊天登入 Session
  • 帳號密碼

6. 自動排程

若使用者主動啟用自動排程， Return Guard 會依使用者設定的時間間隔， 在 Chrome 瀏覽器運作期間檢查案件。

Chrome 瀏覽器關閉期間， Return Guard 不會在背景獨立執行。

7. 是否將資料傳送給第三方

Return Guard 不會販售使用者資料。

除了為完成使用者要求而與賣家中心網站本身進行必要通訊外， Return Guard 不會將案件資料、登入資訊或處理紀錄 傳送給廣告商、資料仲介商或其他第三方作為商業用途。

8. 分析、廣告與追蹤

Return Guard 不使用第三方廣告 SDK， 不進行跨網站追蹤， 也不會基於使用者資料建立廣告或信用評估用途的使用者輪廓。

9. 資料用途限制

Return Guard 僅會基於其單一用途： 「協助賣家管理退貨／退款案件」 使用所需資料。

Return Guard 不會：

  • 販售使用者資料
  • 將資料用於與退貨／退款案件管理無關的目的
  • 使用資料進行信用評等或貸款判斷
  • 建立與本擴充功能用途無關的使用者行為資料庫

10. 資料保留

處理紀錄會保存在使用者自己的瀏覽器本機， 直到使用者清除擴充功能資料、解除安裝擴充功能， 或主動清除處理紀錄。

暫時性的登入與工作階段資訊不會作為長期備份內容保存。

11. 使用者控制

使用者可以：

  • 關閉自動排程
  • 切換自動或手動模式
  • 清除本機處理紀錄
  • 匯出或匯入處理紀錄
  • 解除安裝 Return Guard

12. Chrome Web Store Limited Use

Return Guard 對從 Chrome 擴充功能取得或處理的使用者資料之使用， 將遵守 Chrome Web Store Developer Program Policies， 包含 Limited Use 要求。

13. 政策更新

若 Return Guard 的功能或資料處理方式發生重大變更， 本隱私權政策可能會更新。 最新版本會公布於本頁面。

14. 聯絡方式

若你對本隱私權政策或 Return Guard 的資料處理方式有疑問， 請透過 Return Guard 的 Chrome Web Store 項目頁面與發布者聯絡。
